Student Placement Prediction System

An AI-powered web application that predicts whether a student is likely to be placed based on academic performance and other important attributes.

📌 Project Overview

The Student Placement Prediction System is developed using Machine Learning to estimate whether a student is likely to secure a campus placement. The model has been trained using historical placement data and analyzes several academic and personal factors such as SSC percentage, HSC percentage, Degree percentage, MBA percentage, Employability Test score, Work Experience, Specialisation, Gender, HSC Stream, and Degree Type.
